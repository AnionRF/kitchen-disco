# Kitchen Disco 厨房迪斯科

一款手绘风格的单键节奏烹饪游戏。跟随音乐，使用空格完成切肉、裹粉、搅拌、烘焙和裱花，让每一次操作落在节奏点上。

## 启动步骤

1. 在 Windows 电脑上打开 `builds/level-01` 文件夹，双击 `kitchen-disco.exe`。试玩程序已包含游戏资源，无需安装 Godot。
2. 开场动画结束后，自动进入关卡选择页面。也可以按空格或 Enter 跳过开场。
3. 点击关卡卡片开始游玩：
   - **Prologue / Crispy Chicken Strips**：序章「香酥鸡柳」，约 55 秒，适合首次体验。
   - **Level 1 / Fruit Cream Cake**：第一关「水果奶油蛋糕」，约 60 秒。
4. 游戏首次启动默认使用英文。点击选关页面右下角齿轮，在 **Language / 语言** 中切换为简体中文；设置会保存。

建议先体验序章，并打开声音或佩戴耳机。设置中可以分别调节总音量、音乐、音效和节拍偏移，也可以切换全屏或窗口模式。

## 操作方式

做饭只需要使用空格键，鼠标用于选择关卡和点击菜单按钮。

| 操作 | 按键或方式 |
| --- | --- |
| 点按操作 | 在节奏点到达时按一下空格，每个节奏点对应一次点按 |
| 长按操作 | 在起点按住空格，保持到结束点后松开 |
| 暂停 | 游戏中按 Esc |
| 继续游戏 | 暂停后点击 Continue / 继续，或按 Enter |
| 重新挑战 | 游戏中按 R，或在结算页面点击 Try Again / 再来一次 |
| 返回选关 | 点击 Level Select / 返回选关 |
| 静音切换 | 游戏中按 M |

### 如何判断按键时机

- **食材和厨具轮廓**：观察目标外侧由大到小收拢的高亮轮廓，在轮廓贴合目标时操作。多个目标出现时，按编号顺序完成。
- **绕碗搅拌**：在 Milk & Oil、Flour、Yolks 中的连续搅拌阶段，搅拌器会沿碗内轨道顺时针移动。轨道上最多提前显示三个标记，搅拌头经过对应标记时按空格。按键不会重置搅拌器位置。
- **长按目标**：青色提示表示长按。起点按住后，观察进度条和轮廓变化，在结束点松开。松开本身没有额外音效。

成功操作会触发鼓声和视觉反馈。若感觉听到的节拍与显示的时机不一致，可以暂停进入设置，微调 **Timing offset / 节拍偏移**。

## 玩法概述

### 序章 香酥鸡柳

前约 14 秒通过示范介绍点按与长按；出现「YOUR TURN!!! / 到你了！！！」后，进入正式操作。

玩家跟随音乐依次切鸡肉、裹粉、炸制与沥油，最后完成鸡柳。切下的肉条会留在案板上，裹粉和炸制也会呈现对应的食材变化。本关共 40 个点按和 8 个长按操作。

### 第一关 水果奶油蛋糕

跟随一首约一分钟的音乐，从分离蛋清蛋黄开始，依次完成牛奶与油的搅拌、加入面粉、加入蛋黄、打发蛋清、翻拌、入模、烘焙、奶油裱花和水果装饰。

关卡共 67 个节奏点，包括 47 个点按和 20 个长按。下方分段进度条显示当前烹饪步骤与整首音乐的完成进度。长按会推进相应动画；裱花完成后，奶油花会保留在蛋糕上，水果按操作依次落位。

### 评分与反馈

- **Perfect**：按键时机准确。
- **Good**：有少量偏差，仍成功完成操作。
- **Miss**：错过目标，或长按的起止时机不正确。

连续成功操作会积累连击；失误会中断连击。音乐结束后显示本次成绩，玩家可以重新挑战或返回选关。蛋糕关结算还会展示 Perfect、Good、Miss 的数量、最高连击和菜品评价，并保存最高成绩。
